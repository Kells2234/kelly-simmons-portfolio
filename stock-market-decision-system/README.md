# Automated Stock Market Decision System

## Project Overview

This project is a Python-based market analysis system designed to identify and rank potential stock opportunities using a repeatable, data-driven process.

The system combines historical price data, technical indicators, market momentum, volatility, trading volume, news sentiment, and machine-learning-based scoring.

## Business Question

How can market data, technical analysis, and sentiment be combined into a consistent screening process that helps prioritize potential investment opportunities?

## Analysis Performed

The system evaluates:

- Historical stock prices
- Short-term and medium-term returns
- Relative Strength Index
- Moving averages
- MACD
- Price momentum
- Volatility
- Trading volume
- Volume spikes
- News sentiment
- Machine-learning scores
- Composite investment rankings

## Analytical Process

1. Collect market data from financial data sources.
2. Clean and standardize the data.
3. Calculate technical indicators.
4. Measure price momentum and volatility.
5. Retrieve and analyze recent financial news.
6. Create analytical features for each security.
7. Generate a composite score.
8. Rank the strongest opportunities.
9. Export the results for review.
